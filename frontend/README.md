# EduVerse Frontend 🎨

Built with Next.js 15 (App Router), TypeScript, and Tailwind CSS.

## Overview
The EduVerse frontend provides an interactive student dashboard, real-time AI tutor interface, gamified shop, leaderboard, and dynamic exam engine.

## Key Modules
- `/app/dashboard`: Central student hub showing streak, active quests, and enrolled courses.
- `/app/courses/[courseId]`: Interactive lesson player with integrated AI tutor chat drawer.
- `/app/interview`: AI-powered mock technical interview simulator.
- `/app/shop`: Spend earned XP on custom avatars, borders, and badges.
- `/app/verify`: Public verification page for generated PDF certificates.

## Quick Start
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to start.
